# G-Taxi — Project Context (compact)

## Stack
- Rider app: Expo SDK 52 / React Native / TypeScript
- Driver app: Expo SDK 52 / React Native / TypeScript
- Admin: Vite / React / TypeScript
- Backend: Supabase (Postgres + PostGIS + Edge Functions in Deno)
- Payments: Stripe (PaymentIntents, PaymentSheet, webhooks)
- Maps: Mapbox + react-native-maps
- Auth: Supabase Auth (email/password)
- 23 edge functions, 30+ DB migrations, Rider app is primary

## Key Rules (never violate)
- Edge functions: resolve identity from JWT, never client-supplied IDs
- DB connections from edge functions: port 6543 (not 5432)
- Wallet deductions: SELECT FOR UPDATE inside BEGIN/COMMIT
- Stripe webhook: verify signature from RAW body (req.text() first)
- SUPABASE_SERVICE_ROLE_KEY never in client bundles
- Ride state machine: searching → assigned → arrived → in_progress → completed → payment_confirmed → closed
- Driver gets 81% across all verticals
